# Information to Decision Map

A raw information item enters the core evidence set only through this chain:

```text
SOURCE → FACT → EVENT → AFFECTED SECURITY → MECHANISM → EXPECTED IMPACT → THESIS IMPACT → DECISION IMPACT
```

| Gate question | Required answer |
|---|---|
| What changed? | A dated fact with source reference |
| What is affected? | One or more identified securities or a market-wide context |
| Why does it matter? | A defensible economic or market mechanism |
| What horizon applies? | Investment, swing, execution, or context |
| What could change? | Buy/watch/hold/reduce/exit/no-action or only monitoring |
| What confirms it? | A future or independent evidence condition |
| What invalidates it? | A stated contradiction or expiry condition |
| When does it expire? | Explicit event/freshness date |

If the item cannot answer these questions, it is classified as context or discarded. Multiple reports derived from one underlying fact must share a fact identity or dependency marker and must not count as independent confirmations.
