# News and Information Value Audit

The production value of news is not article count. It is whether a dated, attributed fact can confirm, contradict, invalidate, or require monitoring of a security thesis.

| Classification | Core decision treatment |
|---|---|
| Material corporate event | Attach to affected ticker, classify mechanism/horizon, include as catalyst or risk |
| Thesis confirmation | Add supporting evidence only when independent of existing fact |
| Thesis contradiction | Add contradicting evidence and trigger reassessment |
| Macro event | Feed macro/country context with explicit expiry; never create ticker BUY alone |
| Duplicate report | Link to the same underlying fact; do not double-count |
| Unattributed or legally unusable item | Exclude from core evidence |
| No plausible decision impact | Context or discard |

The existing event platform and provenance path should remain the implementation base. The improvement is governance: every new news collector must declare its expected event class, affected-entity mapping, freshness, decision consumer, and duplicate strategy. No additional news collectors are justified solely by coverage volume.
